Click a staff to place a note, or type A–G to enter notes at the cursor (Shift+letter adds to a chord, 0 = rest, . = dotted, = sharp, - flat, N natural). Keys 1–8 set duration: 64th, 32nd, 16th, 8th, quarter, half, whole, breve. The Key menu sets the key signature from the cursor bar onward (pick a bar first to change key mid-score).
